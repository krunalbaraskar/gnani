# Bolo

Real-time AI copilot for calls and meetings in Indian languages. Bolo listens to both
sides of a call, transcribes them live with Gnani speech-to-text (Hindi, Tamil and other
Indian languages, plus code-mixed speech like Hinglish), and shows short reply
suggestions in a small overlay.

> Work in progress. Full documentation comes with later milestones.

## Scripts

| Command             | What it does                               |
| ------------------- | ------------------------------------------ |
| `npm run dev`       | Start the app with hot reload              |
| `npm run build`     | Build main, preload and renderer to `out/` |
| `npm run lint`      | ESLint                                     |
| `npm run typecheck` | TypeScript, Node and web projects          |
| `npm test`          | Vitest                                     |
